# The weeks — detailed plans

The whole picture — current state, decisions, every work order — is [PLAN.md](PLAN.md). One document per week
below. On the week's first day `tech-lead` turns its work orders into `WO-###` files in
`docs/agent-workspace/work-orders/`, freezes any shared contract (`CT-###`), and the owners build. The gate runs
on Friday before the demo to Telcron.

Week 1 (Sat 14 – Fri 20 Nov) was the foundation: schema, API, Worker, web app, dev deploy, pipeline, and much of
the catalogue, screening, community and rewards. Its outcome is in PLAN §2 and the worklog.
