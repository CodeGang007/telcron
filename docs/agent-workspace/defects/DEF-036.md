# DEF-036 — When the API cannot be reached, pages say the product does not exist

Found by browser-qa-engineer on 2026-11-22 (WO-017 run 2, local stack @ 706b0f8) · Owner: frontend-engineer · Severity: S3
Status: FIXED-PENDING-QA

## What happens
With the API unreachable (requests aborted in Playwright):
- `/products/northwind-chillmate-31` shows "We could not find that product · Search again". A network
  failure is reported as a missing product.
- `/search?q=blender` shows "Cannot reach Telcron. Check your connection and try again." and, below it,
  "No product matches “blender” · Check the spelling…": it claims a product the catalogue holds does not exist.

## What should happen
A product page distinguishes 404 (`product_not_found`) from every other failure and offers "Try again". The
search page shows the empty state only when the request succeeded with zero results.

## Repro
Block `http://localhost:4310/**` (devtools request blocking or stop the API) and open both URLs.

## Evidence
- `frontend/src/pages/Product.tsx:200-203` any `product.error` → "We could not find that product".
- `frontend/src/pages/Search.tsx:20-24` the error notice and the empty state are not exclusive.
- Probe output: `{"apiDown": {"text": "We could not find that product\nSearch again", "spinner": 0}}`.
- No spinner hangs: both pages leave the loading state.

## Fix
frontend-engineer, 2026-11-22, on `week-02` @ 3e99ad4 (uncommitted).
`explain()` says "Could not reach Telcron. Check your connection and try again." for a network failure and
"Could not reach Telcron. Try again in a moment." for a 5xx without a known code. `useLoad` exposes `notFound` (404
only). Product page: "We could not find that product" only on 404, otherwise "This product could not be loaded" +
Try again. Search, Recalls: the empty state shows only when the request succeeded; the error has Try again. The same
"failure shown as empty" was fixed on Wallet (said "Your wallet is empty"), its alerts, Rewards (skeleton forever),
Leaderboard (no error shown), Report ("no passport yet") and the home page figures.
Gate: `npx tsc --noEmit` 0 errors; `npm run build` built. Browser walk not run (stack was not up).
