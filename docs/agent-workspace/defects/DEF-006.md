# DEF-006 — AWS dev: budget alerts nobody, Lightsail leaves port 22 open

Found 2026-11-15 · Owner: infra-deploy-engineer · Severity: S3
Status: OPEN

## What happens
The `telcron-monthly` budget was created without a notification, so going over USD 22 alerts nobody.
The Lightsail instance uses its blueprint's default firewall, which opens port 22 to the internet as
well as 80 and 443. The second point is the blueprint's documented default and was not checked in the
console.

## What should happen
A budget alert to a named person at 80% and 100%. Port 22 on the web host closed, or limited to the
console's browser SSH, once the deploy method is chosen (WO-002).
