# DEF-006 — AWS dev: four things to tighten

Found 2026-11-15, extended 2026-11-16 · Owner: infra-deploy-engineer · Severity: S3
Status: OPEN — item 3 closed with evidence 2026-11-22; items 1, 2, 4 prepared, waiting on the human (WO-020)

1. The `telcron-monthly` budget has no notification, so going over USD 22 alerts nobody.
2. The Lightsail host has port 22 open to the internet (key-only). Its unused blueprint stack is now
   stopped and disabled; the port was used to set the host up and is not needed for releases.
3. The application's database role on dev holds `rds_superuser`, because the same role creates the
   extensions and runs the migrations.
4. The backend image is built on the 1 GB host at deploy time.

## What should happen
A budget alert to a named person. Port 22 closed or restricted. A narrow application role and a separate
migration step. A registry the host can read without new credentials.
