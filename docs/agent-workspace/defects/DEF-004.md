# DEF-004 — No way to get new verification codes

Found 2026-11-15 during WO-001 · Owner: platform-identity-engineer · Severity: S3
Status: OPEN

## What happens
A user who closes the sign-up screen before entering both codes has an account they can sign in to but can never verify: there is no resend endpoint and no standalone verify screen.

## Evidence and state
`backend/app/modules/identity/router.py` has no resend route; `frontend/src/pages/Member.tsx` `Gate` tells the user so. Covered by WO-005.
