# DEF-035 — The "Full hazard report" bought with 50 TelCoins is free to everyone at the same URL

Found by browser-qa-engineer on 2026-11-22 (WO-017 run 2, local stack @ 706b0f8) · Owner: tech-lead (spans `modules/rewards` — community-rewards-engineer — and `frontend/src/pages/Report.tsx` — frontend-engineer) · Severity: S3
Status: IN PROGRESS — human chose (a) 2026-11-22; contract CT-002; fix logged in WO-019

## What happens
Redeeming `hazard_report_pdf` spends 50 confirmed coins and records `fulfilment = {"report": "/products/<id>/report"}`.
The report page is built only from the public product and passport reads; a visitor with no account opens
`/products/contoso-fastcharge-65w/report` and sees the same report. It is an HTML page, not a PDF. A member
therefore spends coins for nothing they did not already have (blast radius 2: coins effectively lost).

## What should happen
Either the report is gated on the redemption (an entitlement read), or it is free and not sold. WO-019 is
changing redemptions; this should be decided there.

## Repro
1. As a member with 50 confirmed coins, redeem "Full hazard report (PDF)" for a product on `/rewards`.
2. Sign out, open `/products/<slug>/report` → full report, no sign-in, no charge.

## Evidence
- `frontend/src/pages/Report.tsx:12-13` loads `/products/{slug}` and `/products/{slug}/passport` only.
- Probe at 390 px and 1280 px as visitor: `/products/contoso-fastcharge-65w/report` h1 "Contoso FastCharge 65W USB-C…", no API error.
- `redemptions` row: `hazard_report_pdf | fulfilled | {"report": "/products/01a1d9aa-…/report"}`.

## Blocked on human
Two readings of D13 ("the printable hazard report stays"), which produce different work:
- (a) **Sell access to the print page**: the report page asks the API whether the caller holds a fulfilled
  `hazard_report_pdf` redemption for that product (new contract, rewards + frontend); visitors and non-buyers see
  the public passport instead. The data in it stays public (passports need no account), so the 50 coins buy a
  print layout only.
- (b) **Make the report free and stop selling it**: link the print page from every passport, take
  `hazard_report_pdf` off sale with a migration, refund past purchases through `coin_refund_redemption`.
tech-lead would pick (b): the non-negotiable "passport reads need no account" makes (a) a charge for a layout of
free data, and D13's wording was decided before anyone noticed the page is open. Nothing is changed until the
human chooses; WO-019 stays as built (two items on sale).
