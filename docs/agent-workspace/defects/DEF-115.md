# DEF-115 — The passport says Reddit, X, YouTube and the web were searched when no web search provider is configured

Found by browser-qa-engineer on 2026-11-23 (weeks 1-2 sweep, local stack @ 189a1c6, Worker running, COIN_CONFIRM_DELAY 15 s) · Owner: data-ai-engineer (research stats) with frontend-engineer (copy) · Severity: S3
Status: OPEN

## What happens
Every passport's "What official sources and the web say" card lists "US CPSC and FDA, UK Product Safety, government
safety regulators …, the open web, and what owners report on Reddit, X, YouTube and marketplace reviews", then
"Searched 11/22/2026: 5 pages read, none said anything about this product's safety or reliability." The only hint
is a small line "Some sources did not answer last time: web." Admin › Data sources shows the truth for every run:
"partial … 1 source failed — **Web search: no search provider configured.**" A visitor reads "nothing found" where
nothing was searched.

## What should happen
When the web/community search did not run, the card says so plainly ("Web and owner-forum search is not available
yet") and does not count it as searched; "none said anything" only covers sources that answered. An unwired provider
is a named PARTIAL (CLAUDE.md), not a clean result.

## Repro
1. Local stack with no search provider key (the default `.env`).
2. Open any passport, e.g. `/products/northwind-chillmate-31`; read the research card.
3. As admin open `/admin/data-sources` → "Product research runs".

## Evidence
- `frontend/src/components/Research.tsx:95-96` (source list), `:165` ("pages read, none said anything"),
  `:169` (the "did not answer" line).
- Admin run text: "0 recall notices checked · 5 web pages · 0 findings · 1 source failed / Web search: no search
  provider configured." (Which 5 pages were "read" without a search provider is itself worth checking.)
- Whether dev has a search key configured was not checked (dev site out of scope for this run).
