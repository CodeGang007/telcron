# DEF-013 — Literal colours in components: Tailwind palette, hex and rgb() outside the design tokens

Found by qa-test-engineer (WO-017, part A) on 2026-11-22 · Owner: frontend-engineer · Severity: S3
Status: FIXED-PENDING-QA

## What happens
WO-012's acceptance says "tokens only (no literal colours)", and so do CLAUDE.md's non-negotiables and
`telcron-frontend` ("No hex or literal colour in a component"). In `frontend/src` there are **49** uses
of Tailwind's built-in palette (`from-emerald-500`, `text-amber-600`, `to-rose-500`, ...) and **7** hex or
`rgb()` literals. None of them is a token from `src/index.css`.

## What should happen
Every colour comes from the `@theme` tokens in `src/index.css` (`brand*`, `action*`, `ok*`, `warn*`, `danger*`,
`gold*`, `ink`, `muted`, `line`, `panel`, `warm`, `night*`, `neutral-tint`). If the category tiles, podium and
stat-card gradients need more colours, add them as tokens.

## Repro
```
cd frontend/src

grep -rnE "#[0-9a-fA-F]{6}\b|rgb\(" --include=*.tsx . | wc -l                                                      # 7
```

## Fix
By frontend-engineer on 2026-11-22, branch `wt/frontend`, commit `aa293fe`. Status: FIXED-PENDING-QA

- `src/index.css` `@theme` gains the tokens the components needed, with the exact values they used, so
  the look is unchanged: `brand-blush`, `brand-soft`, `ok-glow`, `ok-bright`, `ok-deep`, `warn-bright`,
  `flame`, `gold-light|mid|deep|ink|dark`, `silver-light`, `silver`, `bronze-light`, `bronze`, `violet`,
  `cat-<category>-from|to` for the ten category tiles, and shadows `brand`, `brand-sm`, `hairline`,
  `float`, `deep`. `.text-gradient` also uses tokens now.
- Components use those names: `components/ui.tsx`, `Assistant.tsx`, `IdentifyNew.tsx`, `SearchBox.tsx`,
  `pages/Home.tsx`, `Leaderboard.tsx`, `Rewards.tsx`, `Scan.tsx`, `Wallet.tsx`. The level ring's track is
  `stroke-white/15`. The confetti reads its colours from the tokens at run time (`src/lib/tokens.ts`).
- `bg-white`/`text-white`/`black` with opacity are kept: white and black are not brand colours.
- **Left for tech-lead** (owner of `components/Layout.tsx`):
  line 127 `shadow-[0_10px_24px_-8px_rgb(226_55_68/0.8)]` -> `shadow-brand-sm`;
  line 159 `shadow-[0_1px_0_rgb(15_23_42/0.02)]` -> `shadow-hairline`.
