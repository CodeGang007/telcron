# DEF-041 — Research turns a model-labelled recall on any official domain into a recall carrying this product's own name

Found by security-auditor on 2026-11-22 (WO-017) · Owner: data-ai-engineer · Severity: S3
Status: OPEN

## What happens
`backend/app/modules/research/service.py:174,195-196`, `web.py:26-28,53-57`: the recall row gets the product's own name and brand, so screening (`screening/service.py:109-119`) produces a guaranteed `near_match`, a needs-information badge and recall alerts even when the notice only names the brand. Any `*.gov.uk`/`*.canada.ca` subdomain counts as official.

## What should happen
The recall stores the product name the notice prints; linking needs the model number or a name match in the page text; regulator hosts narrowed to an explicit list.
