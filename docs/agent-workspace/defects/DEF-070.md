# DEF-070 — Research tests reach saferproducts.gov over the network

Found by data-ai-engineer on 2026-11-22 (WO-054) · Owner: data-ai-engineer · Severity: S4
Status: OPEN

## What happens
Research tests with a brand call the real `cpsc.search`: `CPSC_FIXTURE` is unset and the autouse fixture in
`backend/tests/conftest.py` does not replace the CPSC client, so the suite calls the live registry.

## What should happen
Tests never reach a provider; the CPSC client is replaced wholesale (recorded fixture) like the others.

## Repro
Run `backend/tests/test_research.py` offline: the brand cases fail or hang.

## Evidence
Reported in WO-054's log (wt/w2-gaps).
