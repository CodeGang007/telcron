# DEF-048 — Startup accepts DEV_EXPOSE_CODES outside local/test; recipient address logged at info

Found by security-auditor on 2026-11-22 (WO-017) · Owner: platform-identity-engineer · Severity: S4
Status: FIXED-PENDING-QA

## What happens
`core/config.py:27,90-94` no guard; `identity/mailer.py:61` logs the address; `service.py:56` provider error text into `auth_events`.

## What should happen
A settings validator refuses `DEV_EXPOSE_CODES=true` unless the environment is local/test; addresses masked in logs; provider error codes, not text, stored.
