## Blocked on human
Rotate the four keys. No AWS resource is created or changed; the only AWS action is writing new values into
the existing app secret (Secrets Manager `PutSecretValue`: a new version of the same secret — no new resource,
no added monthly cost; the secret already costs USD 0.40 a month and API calls are fractions of a cent).
For each key: create the new one, write it with the "Replace a key (live)" command in
`docs/runbooks/api-keys.md` (reads from the clipboard, never printed), run "Apply now" (or one apply after all
four), check the feature, **then revoke the old key at the provider**, and replace it in every local `.env`
that holds it (yours and the teammate's). Look at each provider's usage page for use you do not recognise.
1. **Groq (`LLM_API_KEY`)**: console.groq.com → API Keys → Create API Key (name it for Telcron dev) → write to
   `LLM_API_KEY` → apply → ask the product assistant a question → delete the old key in the same list. Free plan,
   no cost.
2. **Tavily (`TAVILY_API_KEY`)**: app.tavily.com → API Keys → create a new key → write to `TAVILY_API_KEY` →
   apply → "Search again" on a product → delete (or regenerate) the old key. Free plan (1,000 searches a month),
   no cost.
3. **Mail app password (`SMTP_PASSWORD`)**: on the Google account that is `MAIL_FROM`, myaccount.google.com/
   apppasswords → remove the app password used by Telcron → create a new one → write to `SMTP_PASSWORD` (spaces
   are dropped by the deploy) → apply. Check by having a code sent to an address you own (local, or on dev once
   sign-up is open); also review the account's recent security activity. No cost.
4. **Gemini (`GEMINI_API_KEY`) from a Telcron-owned project**: console.cloud.google.com → New project (owned by a
   Telcron account; **do not link a billing account**, so it stays on the free tier at no cost) →
   aistudio.google.com → Get API key → Create API key → choose that project → in the Cloud console restrict the
   key to the Generative Language API → write to `GEMINI_API_KEY` → apply → check (the assistant still answers
   when Groq's daily allowance is spent; or a photo read) → ask the owner of the other project to delete the
   borrowed key there.
