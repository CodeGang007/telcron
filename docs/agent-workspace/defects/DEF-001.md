# DEF-001 — `search_queries.user_id` is required in the ERD but anonymous search needs it empty

Found 2026-11-15 during WO-001 · Owner: database-engineer · Severity: S4
Status: RESOLVED — the schema requires `user_id`; the backend logs searches of signed-in members only

## What happens
The ERD (page 9) shows `search_queries.user_id` as `uuid → users`, not nullable. Requirement F1 lets a visitor search without an account, and the technical documentation says search queries are logged in phase one. Both cannot hold.

## Evidence and state
Implemented as nullable in `backend/app/models/feed.py`. Telcron should confirm, or say that anonymous searches are not logged.
