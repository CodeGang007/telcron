# CT-001 — GET /api/v1/flags

Status: FROZEN (2026-11-22, tech-lead) · Producer: platform-identity-engineer · Consumer: frontend-engineer

## Caller
Public (no account). Same answer for everyone in phase one; `rollout` is not evaluated yet.

## Request
No parameters.

## Response 200
`{"flags": {"<code>": true, ...}}` — every row of `feature_flags` with `is_enabled = true`, keyed by `code`.
Disabled and unknown flags are absent (the client treats absent as off). `Cache-Control: public, max-age=60`.

## Errors
| Status | Code | When |
| --- | --- | --- |
| — | — | none beyond the API's standard 5xx envelope |

## Side effects
None. Server side, `app.core.flags.is_enabled(session, code) -> bool` reads the same table (absent = off);
a module hides an unfinished route behind it by answering 404 `not_found` when the flag is off.
