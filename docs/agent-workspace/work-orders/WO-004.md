## Why
Hazard scores currently come from `StubScorer`, a keyword placeholder. Requirement F3 needs the real model.

## Scope
`BedrockScorer` behind the existing `Scorer` protocol (strict JSON, prompt version recorded, tokens and cost in
`ai_invocations`); Titan embeddings for products, images and recalls; nearest-recall retrieval with pgvector in
`_recall_candidates`; `POST /identify` from a photo; the 20-product evaluation set.

## Blocked on human
On 2026-11-15 both the CLI and the Bedrock playground returned `ThrottlingException: Too many tokens per day`
for Nova Lite and Nova Micro in us-east-2: a new account's quota is effectively zero. Someone must request a
quota increase (or wait for AWS to raise it). Also: `amazon.titan-embed-image-v1` was not in the model list for
us-east-2; only `amazon.titan-embed-text-v2:0` was. The region or the embedding model must be decided.
