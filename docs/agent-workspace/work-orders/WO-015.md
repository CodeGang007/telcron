## Built
- `services/embedder/`: our own embedding service (FastAPI + fastembed, BAAI/bge-small-en-v1.5, MIT,
  384 dims, CPU). Titan is throttled to zero on the account's Free plan; the 1 GB backend host is too
  small, so it runs in the new single host's Compose (WO-016). Locally: `make embedder`.
- Schema (spec first): `product_embeddings`, `evidence_embeddings`, `chat_threads`,
  `chat_messages` (append-only), phase 2. Fresh databases get them from schema-next; the dev database
  (phase 2 applied earlier) from `db/migrations/20261122120000_vectors_and_assistant.sql`, a guarded
  copy of the generated statements. Both paths compared column by column, constraint, index and
  trigger: identical. Model `bge-small-en-v1.5:384` activated with one HNSW index per table.
- Indexing: every new passport version queues `ProductIndexRequested` (queue `index`); the Worker
  embeds the product (identity + research findings) and its evidence, re-embedding only on change;
  recalls too. Nightly catch-up 04:00 UTC.
- Search: name matching fused with meaning (reciprocal rank); distance limit 0.38 calibrated on the
  real model (right matches 0.22–0.41, wrong ≥ 0.40). Falls back to names if the embedder is down.
- Screening: recall candidates also by meaning (distance < 0.2), same brand still required.
- Safer alternatives: similar products with a verified passport and trust ≥ this one's (≥ 60),
  ranked by trust, then owner rating, then similarity. Store links are plain country-aware searches
  (Amazon, Flipkart, Walmart, Argos, Google Shopping…), no affiliate tags. "Where to buy" is low-key.
- Assistant: `GET/POST /products/{slug}/assistant` (signed in). Memory = the member's thread per
  product (last 8 turns). Retrieval = the product's evidence nearest the question. Checks in code:
  citations must be offered labels; an answer with no valid citation or whose words are mostly not
  in its sources/facts/question is replaced with an honest "can't find that"; a decline cites
  nothing; 40 questions/day. Knows the verified alternatives.
- Evals: `make eval-assistant` (8 cases: recall, unknown allergen, injection, off-topic, complaints,
  memory, medical, no-recall). 5/8 → 8/8 after: a refusal cites nothing; the grounding check
  tolerates word endings and question words (it had rejected a faithful paraphrase). One case's
  banned phrase was narrowed (it matched an honest "I don't know whether…"): a test bug, noted in the
  case file.
- UI: assistant side panel with suggested questions and source chips; "What official sources say";
  safer alternatives; progress steps on the new-product flow; signed-in home button.
