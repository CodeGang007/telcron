# WO-005 — Send the verification codes and add a resend endpoint

Owner: platform-identity-engineer → security-auditor · Opened 2026-11-15
Status: OPEN · Size M

## Why
Codes are generated and hashed but never sent; locally they are shown on screen. Nobody can sign up on a deployed build.

## Scope
An email client (SES) and an SMS client (provider to be chosen), each the only file talking to its provider;
`POST /auth/resend` with a per-user rate limit; the verify screen reachable after leaving sign-up (DEF-004).

## Acceptance
- [ ] With `DEV_EXPOSE_CODES` off the register response carries no codes.
- [ ] Resend is limited and does not reveal whether an email is registered.

## Blocked on human
SMS sender registration can take weeks per country (risk 10): which countries launch first?
