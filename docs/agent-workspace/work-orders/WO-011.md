# WO-011 — Converge the backend on the real database schema

Owner: tech-lead decomposes → database-engineer, platform-identity-engineer, community-rewards-engineer · Opened 2026-11-15
Status: DONE-PENDING-QA (merged into `main` 2026-11-15) · Size L

## Why
DEF-005. Two schemas exist for the same database. Branch `feat/database-schema` holds the designed one:
`docs/database/schema_spec.py` generates dbmate SQL migrations, with rules enforced in the database and
a test suite. `backend/app/models/` and `backend/alembic/` on `main` were built from the ERD pictures
before that branch was known.

## What was compared (2026-11-15, by script)
- Tables: 90 on each side, same names. Columns: same names in every table.
- Enum types: 61 on each side, same names. **54 have different values.**
- Rules: that branch has 13 triggers and SQL functions `coin_earn`, `coin_confirm_due`, `coin_spend`,
  `coin_redeem`, `coin_apply_hold`, `coin_resolve_hold`, `coin_clawback`, `coin_lock_balance`. `main`
  does the same work in Python (`modules/rewards/service.py`) with direct inserts and updates.
- Not compared: column types, nullability, defaults, constraints, indexes, partitioning.

## Scope
1. Land `feat/database-schema` on `main` (its author). Both sides add `.gitignore`, `.env.example`,
   `docker-compose.yml`, `CLAUDE.md` and `README.md`: keep both; the compose file becomes that branch's
   `db` service plus `redis` from here.
2. Apply phases 2 and 3 (`db/schema-next/`) as migrations. The application uses about twenty tables
   outside phase 1, among them `hazard_assessments`, `coin_ledger_entries`, `review_tasks` and
   `outbox_events`.
3. Remove `backend/alembic/`. Keep `backend/app/models/` as a mapping of the generated schema, with
   enum values copied from the spec.
4. Send every TelCoin write through the `coin_*` functions and delete the Python duplicates.
5. Settle the values the application needs and the spec lacks: `auth_provider` has no `password`;
   `user_role` is `user, moderator, admin` (the application uses `safety_reviewer`); `token_purpose` and
   `auth_event_type` use different names. Raise each with the spec's author; do not add values quietly.
6. One local PostgreSQL. That branch's image has PostGIS; its port, 5433, is taken on at least one
   developer machine.
